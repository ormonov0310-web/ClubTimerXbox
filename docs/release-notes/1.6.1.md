# Club Timer Xbox 1.6.1

- Ускорено построение игрового журнала сотрудников: вместо повторного перебора всей кассы для каждой игры используется предварительный индекс связей с оплатой. Это устраняет найденный лишний поиск при подготовке снимков для телефона и истории сотрудников.
- Сохранены прежние строки журнала, их порядок, суммы и правила принадлежности выручки. Индекс создаётся заново при каждом расчёте, поэтому новые оплаты и исправления не требуют перезапуска.
- Добавлены проверки совпадения результатов со старым алгоритмом: разные сотрудники и месяцы, платёжные ссылки, повторные записи и обновление исходных данных.

Обновление только для ПК. Касса, зарплата и исторические проводки не переписываются; частота и правила синхронизации Firebase не меняются. Новый APK телефона не требуется.

Исправление направлено на конкретный найденный участок расчёта. Устранение всех возможных причин зависаний пока не подтверждено; эффект на рабочем ПК Салиха предстоит измерить.
