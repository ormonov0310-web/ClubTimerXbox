# Club Timer Xbox 1.5.8

- Автоматическое погашение личного долга сохраняет 200 сом зарплатного остатка с учётом перенесённого плюса или минуса. Пропущенные удержания не догоняются позже; повторный расчёт по старому отчёту не расходует уже переведённые деньги второй раз.
- В меню сотрудника появился пункт «Посмотреть / взять зарплату». Личный код открывает деньги именно этого сотрудника, не меняя действующего администратора и смену. В локальной истории сохраняется получатель и администратор, при котором открыли доступ и получили зарплату. Сами коды в историю не записываются.
- В окне получения зарплаты «Доступно» показывает общий итог. При наличии возврата личного долга ниже отдельно видны «ЗП остаток» и «Из долгов». Отрицательная зарплата остаётся видимой; возврат личного долга не погашает её автоматически.
- После успешной выплаты по центру приложения появляется уведомление «Заберите из кассы … сом наличными» с кнопкой «Забрал». Оно работает для обоих способов получения зарплаты, не блокирует приложение и не создаёт повторного списания.
- Окна меню сотрудника и получения зарплаты подстраиваются под содержимое: длинные подписи переносятся, действия остаются доступными.

Обновление предназначено для ПК. Телефонное приложение не меняется. Исторические
выплаты, удержания, штрафы и премии не переписываются. Просмотр зарплаты и закрытие
уведомления не создают облачных событий; успешная выплата использует существующую
очередь уведомлений. Новых опросов Firebase или периодических загрузок нет.
