# Club Timer Xbox 1.6.4

- Одна закупка может оплачиваться наличными и безналом одновременно. Товары поступают один раз, история закупки остаётся общей, а каждая часть оплаты уменьшает свой денежный остаток.
- Для совместимого приложения владельца добавлено подтверждение смешанной оплаты. Повторная доставка команды и восстановление после прерывания не должны создавать повторный приход товара или повторное списание.
- В приёмке товаров на ПК можно сохранять собственный порядок: удерживайте шесть точек слева и переносите карточку вверх или вниз. Название, фон и поля количества перенос не начинают.
- Поднятая карточка слегка прозрачна, плавно следует за мышью только по вертикали. Соседи освобождают место при достижении их середины передним краем карточки. После отпускания она приземляется в уже выбранное место.
- Порядок приёмки сохраняется отдельно для клуба и не меняет популярность в других списках. Закончившийся товар сохраняет своё место и возвращается на него после пополнения. Введённые количества при переносе не сбрасываются.
- Существующее сворачивание нулевого остатка через 24 часа сохранено. Сортировка, анимация и пересчёт полей не добавляют фоновых обращений к Firebase; прежний порядок автоматической синхронизации не изменён.

Смешанная оплата требует совместимой версии приложения владельца. Старые закупки без сохранённой разбивки оплаты не получают выдуманные суммы. Исторические приёмки, кассовые карточки и другие финансовые записи этим выпуском не исправляются.
