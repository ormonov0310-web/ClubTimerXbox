# Club Timer Xbox 1.6.0

## Ввод и работа с клавиатурой

- Ноль в новых числовых полях показывается подсказкой, а не частью введённого числа. Ввод и вставка больше не добавляют лишний ноль.
- В кассовом окне частичная оплата наличными и безналом сохраняет общую сумму и не позволяет превысить её.
- Поля в окнах зарплаты, смены сотрудника и произвольного времени готовы к вводу сразу после открытия. Enter подтверждает действие через обычную проверку; в произвольном времени сначала выбрана сумма.

## Производительность и закрытие клуба

- Ускорен расчёт краткой дневной выручки; неизменившийся итог используется повторно.
- Подготовка JSON и кодирование снимков перенесены с интерфейса в фоновую работу. Сохранены очередь, повторная отправка после восстановления связи и подтверждение успешной доставки.
- При обычном закрытии уведомление и компактное закрытое состояние клуба отправляются вместе, до полного финального снимка. Старые события из очереди не должны закрывать уже начавшуюся новую смену.
- Добавлены ограниченные локальные замеры этапов подготовки и доставки для дальнейшей диагностики, без отдельной отправки этих замеров в облако.

## Телефон владельца

Эта часть установлена отдельно на подключённый телефон и не входит в ZIP для ПК:

- Уменьшено копирование больших снимков при обновлении состояния, чтобы снизить риск нехватки памяти.
- В настройках добавлена локальная записная книжка подписок Game Pass: аккаунты, связки устройств, карты, общий адрес и цена, напоминания за пять дней до продления.
- Курс иены проверяется раз в день; при отсутствии сети сохраняется последнее значение. Расчёт в сомах ориентировочный, не банковская сумма списания.

Финансовые правила и исторические проводки не переписываются. Полное устранение зависаний Салиха и всех возможных причин вылетов телефона пока не подтверждено; отдельная диагностика отложена.
