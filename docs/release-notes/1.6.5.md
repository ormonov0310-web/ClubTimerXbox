# Club Timer Xbox 1.6.5

- Исправлено повторное появление старого имени сотрудника после переименования. Сохранённый список сотрудников больше не дополняется стандартными именами при каждом запуске; постоянные ID и коды доступа сохраняются.
- Убрано устаревшее исправление по одному имени, которое могло ошибочно переносить новые записи другого сотрудника на прежнего работника.
- Для подтверждённого случая в Салихе подготовлено одноразовое восстановление принадлежности смены, выручки и уже сделанных выплат Мирбека. Суммы и ID кассовых операций не меняются, повторные выплаты не создаются. Старая история другого сотрудника не переносится.
- Перед восстановлением проверяются конкретные записи и создаются локальные резервные копии. После прерывания операция продолжается по сохранённому журналу; если исходные данные изменились неожиданно, запуск останавливается до проверки владельцем, без подбора сумм.
- Отключённые сотрудники не могут начинать новую смену, проводить новые игры и продажи или получать новые премии, рейтинговые начисления и доли бонуса за план. При отключении открытая смена сотрудника закрывается.
- История, ранее заработанные суммы и закреплённые бонусы сохраняются. Договоры долга и их погашение продолжают работать даже для отключённых должников и кредиторов по прежним правилам.
- Новые фоновые запросы, таймеры и слушатели Firebase не добавлены. Автоматическая синхронизация остаётся прежней; восстановление выполняется локально только на подходящем ПК Салиха.

Восстановление предназначено только для проверенного случая на конкретной установке Салиха и не является массовым переименованием истории. Итоговую зарплату необходимо сверить после применения обновления. Новая версия приложения владельца для этих исправлений не требуется.
