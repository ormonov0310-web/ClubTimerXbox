# Конституция архива и очистки данных

Версия: 1.0  
Дата: 2026-08-05

## Статья 1. Назначение архива

1. Закрытый месяц получает компактный неизменяемый архив до удаления подробных записей.
2. Архив является источником исторических отчётов после очистки Firebase.
3. Архив нельзя молча пересчитать по новым настройкам.

## Статья 2. Обязательный состав

Архив хранит выручку игр, товаров и услуг, движение наличных и безнала, расходы, закупы, себестоимость, прибыль, часы, начисления, бонусы, штрафы, выплаты и остаток по каждому EmployeeId, рейтинги, закрытые наказания, версии зарплатных правил и входящие/исходящие остатки месяца.

## Статья 3. Запреты удаления

Нельзя удалять текущий месяц, незакрытый месяц, открытые кассовые разборы, незавершённые операции, невыплаченные обязательства, активные наказания и месяц без проверенного архива.

## Статья 4. Срок хранения

1. Подробные записи последних шести месяцев сохраняются по умолчанию.
2. Более старые подробные записи можно удалить только после проверки контрольной суммы архива.
3. Сам архив и финансовые итоги не удаляются автоматической очисткой.

## Статья 5. Порядок очистки

1. Создать архив.
2. Проверить полноту, суммы, EmployeeId и контрольную сумму.
3. Пометить архив готовым.
4. Удалить только разрешённые подробные записи месяца.
5. Повторно проверить, что исторический отчёт читается из архива.
6. Записать журнал очистки с датой, клубом, месяцем и исполнителем.
