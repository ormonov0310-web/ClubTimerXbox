# Конституция индивидуальной зарплаты

Версия: 1.0  
Дата: 2026-08-05

## Статья 1. Состав зарплаты

1. Зарплата сотрудника состоит из начисления за рабочее время, доли от игровой выручки, бонуса за товары и услуги, прочих бонусов, удержаний и выплат.
2. Рейтинг времени влияет только на новые начисления за рабочее время.
3. Рейтинг выручки влияет только на новые начисления от игровой выручки.
4. Бонус товаров и услуг рейтингом не изменяется.

## Статья 2. Неизменяемость заработанного

1. Любое начисление рассчитывается по версии настроек и рейтинга, действовавшей в момент заработка.
2. Новая ставка, процент или рейтинг не пересчитывают прошлые месяцы и уже заработанную часть текущего месяца.
3. Переименование сотрудника не создаёт нового сотрудника: связь ведётся по устойчивому EmployeeId.
4. Исправления выполняются отдельной компенсирующей записью. Старое начисление не переписывается.

## Статья 3. Версии настроек клуба

1. Настройки клуба хранятся как неизменяемая история версий.
2. В версию входят резерв расходов, доля игровой выручки, почасовая ставка, рабочий график, товарный бонус и правила автоматических бонусов.
3. Изменение общей формулы начинает действовать с начала следующего рабочего дня в 06:00.
4. Уже созданная версия не редактируется. Новое изменение создаёт следующую версию.

## Статья 4. Индивидуальные коэффициенты

1. Каждый сотрудник имеет отдельный базовый процент времени и отдельный базовый процент игровой выручки.
2. Начальное значение обеих веток равно 100%.
3. Допустимый диапазон: от 0% до 120%.
4. Изменение индивидуального процента действует с момента подтверждения владельцем и только на будущий заработок.

## Статья 5. Формулы

1. Начисление времени = часы в оплачиваемом графике × почасовая ставка версии × рейтинг времени / 100.
2. Начисление игр = игровая выручка сотрудника после резерва × доля зарплаты версии × рейтинг выручки / 100.
3. Начисление товаров = выручка товаров сотрудника × товарный бонус версии / 100.
4. Денежное округление выполняется один раз по итоговой сумме однородных начислений, чтобы мелкие операции не теряли сомы.

## Статья 6. Переход месяца

1. Закрытый месяц хранит окончательный снимок начислено, удержано, выплачено и осталось.
2. Невыплаченный остаток переходит обязательством в следующий месяц и погашается по FIFO: сначала самый старый долг.
3. Изменение будущих настроек не изменяет закрытый снимок.

## Статья 7. Ошибочное наказание

1. Досрочное прощение восстанавливает коэффициент только для будущих начислений.
2. Отмена ошибочного наказания восстанавливает коэффициент и создаёт отдельную компенсацию потерянной зарплаты.
3. Компенсация отображается отдельно и не маскируется под игровую выручку или рабочие часы.
