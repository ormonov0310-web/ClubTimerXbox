# Конституция индивидуальной зарплаты

Версия: 1.1
Дата: 2026-08-26

## Статья 1. Состав зарплаты

1. Зарплата сотрудника состоит из начисления за рабочее время, доли от игровой выручки, бонуса за товары и услуги, прочих бонусов, удержаний и выплат.
2. Рейтинг времени влияет только на новые начисления за рабочее время.
3. Рейтинг выручки влияет только на новые начисления от игровой выручки.
4. Бонус товаров и услуг рейтингом не изменяется.

## Статья 2. Неизменяемость заработанного

1. Любое начисление рассчитывается по версии настроек и рейтинга, действовавшей в момент заработка.
2. Новая ставка, процент или рейтинг не пересчитывают прошлые месяцы и уже заработанную часть текущего месяца.
3. Переименование сотрудника не создаёт нового сотрудника: связь ведётся по устойчивому EmployeeId.
4. Исправления выполняются отдельной компенсирующей записью. Старое начисление не переписывается.

## Статья 3. Версии настроек клуба

1. Настройки клуба хранятся как неизменяемая история версий.
2. В версию входят резерв расходов, доля игровой выручки, почасовая ставка, рабочий график, товарный бонус и правила автоматических бонусов.
3. Изменение общей формулы начинает действовать с начала следующего рабочего дня в 06:00.
4. Уже созданная версия не редактируется. Новое изменение создаёт следующую версию.

## Статья 4. Индивидуальные коэффициенты

1. Каждый сотрудник имеет отдельный базовый процент времени и отдельный базовый процент игровой выручки.
2. Начальное значение обеих веток равно 100%.
3. Допустимый диапазон: от 0% до 120%.
4. Изменение индивидуального процента действует с момента подтверждения владельцем и только на будущий заработок.

## Статья 5. Формулы

1. Начисление времени = часы в оплачиваемом графике × почасовая ставка версии × рейтинг времени / 100.
2. Начисление игр = игровая выручка сотрудника после резерва × доля зарплаты версии × рейтинг выручки / 100.
3. Начисление товаров = фактически оплаченная выручка товаров сотрудника ×
   товарный бонус версии / 100. Создание позиции, выдача товара и передача долга
   сами по себе бонус не создают.
4. Денежное округление выполняется один раз по итоговой сумме однородных начислений, чтобы мелкие операции не теряли сомы.

## Статья 6. Переход месяца

1. Закрытый месяц хранит окончательный снимок начислено, удержано, выплачено и осталось.
2. Невыплаченный остаток переходит обязательством в следующий месяц и погашается по FIFO: сначала самый старый долг.
3. Изменение будущих настроек не изменяет закрытый снимок.

## Статья 7. Ошибочное наказание

1. Досрочное прощение восстанавливает коэффициент только для будущих начислений.
2. Отмена ошибочного наказания восстанавливает коэффициент и создаёт отдельную компенсацию потерянной зарплаты.
3. Компенсация отображается отдельно и не маскируется под игровую выручку или рабочие часы.

## Статья 8. Уведомление о самостоятельной выплате

1. После успешной самостоятельной выплаты зарплаты наличными приложение клуба отправляет владельцу уведомление с названием клуба, именем сотрудника и суммой.
2. Уведомление создаётся только после фиксации выплаты в кассе и зарплатном журнале.
3. Уведомление использует ID операции выплаты и не может быть отправлено повторно при повторной синхронизации.
4. При отсутствии интернета событие сохраняется в локальной очереди и отправляется после восстановления связи по общим правилам срока жизни уведомлений.

## Статья 9. Принадлежность товарной выручки

1. Товарный бонус получает сотрудник, при чьей смене деньги фактически приняты.
2. Кто выдал товар и кто принял оплату, сохраняются в истории раздельно.
3. Неоплаченная позиция не входит в зарплату ни одного сотрудника.
4. Передача долга новому сотруднику не создаёт начисление. Начисление появляется
   только после успешного платежа.
5. Старые закрытые начисления не перераспределяются после обновления. Новая модель
   применяется к новым и активным неоплаченным позициям.

## Статья 10. Принадлежность игровой выручки

1. Игровое начисление получает сотрудник, который фактически принял конкретный
   платёж ККМ за тариф, открытый режим или добавление времени.
2. Если один сеанс оплачивался частями при разных сотрудниках, закрытие ТВ не
   объединяет эти части в доход одного сотрудника.
3. При досрочном возврате игровая выручка сохраняется от старых платежей к новым:
   возвращаемая часть сначала снимается с последнего платежа.
4. Старый сеанс без платёжных ссылок сохраняет прежнюю принадлежность. Новая
   детализация не пересчитывает уже закрытые зарплатные периоды.

## Статья 11. Дневная история заработка

1. Дневная история строится по рабочим дням клуба с 06:00 до 05:59, а не путём
   равномерного деления месячной зарплаты.
2. Для времени и игр отдельно сохраняются базовая сумма при рейтинге 100%,
   фактические рейтинги периода, прибавка или потеря от рейтинга и окончательно
   начисленная сумма.
3. Если ставка, формула или рейтинг менялись внутри дня, заработок делится на
   части по времени действия каждой версии. Дневной итог равен сумме этих частей.
4. Бонусы дня включают товарный и сервисный бонус, автоматические бонусы и
   премии владельца. Они не подменяют заработок за время или игры.
5. Сумма дневных итогов обязана точно совпадать с окончательным начислением за
   месяц. Округление не может создавать или терять деньги.
6. При закрытии месяца дневные итоги закрепляются в архиве вместе с месячной
   зарплатой. Последующие изменения ставок и рейтингов их не пересчитывают.
7. Исправление закрытого дня выполняется отдельной компенсирующей записью;
   исходная запись не переписывается.
