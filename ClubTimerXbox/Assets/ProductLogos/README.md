# Product logo library

These images are prepared as same-size dark cards for the sale item grid.
To replace a logo later, keep the same file name and rebuild the app.

- `tornado.png` -> ТОРНАДО
- `letsgo.png` -> Летс Го 1 литр
- `apple.png` -> Яблоко 1 литр
- `sultan-tea.png` -> Султан Чай
- `piko.png` -> Пико 1 литр
- `cola.png` -> Кола 1 литр
- `xbox-gamepad.jpg` -> Джойстик
